# CityPulse — 3 Minute Pitch

## Opening — 20 seconds

"Cities generate a lot of civic information, but residents and decision-makers often see those signals separately. CityPulse brings them into one understandable operational view."

## Problem — 30 seconds

"A traffic slowdown, an incident cluster, a weather event or a citizen complaint can look unrelated when they live in different systems. The challenge is turning heterogeneous signals into one usable picture without pretending that a correlation is automatically a cause."

## Solution — 45 seconds

"CityPulse ingests civic signals, normalizes them into a common schema, timestamps them, checks for unusual patterns and explains the result in plain language. Residents can also submit issues, which are persisted and surfaced in the operational view."

## Demo — 70 seconds

Show the dashboard → traffic layer → data fusion → Tonk Road correlation → AI question → citizen report → operations panel.

## Technology — 25 seconds

"The frontend is HTML, CSS and JavaScript with Leaflet. The backend is FastAPI with SQLite. Weather and air-quality enrichment can use Open-Meteo. The intelligence layer is a transparent rules engine with grounded responses."

## Close — 20 seconds

"The important part is the pipeline: ingest, normalize, compare, explain and act. The same architecture can later connect verified city data sources and authority workflows without changing the core product."
