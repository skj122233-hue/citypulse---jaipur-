# Data Sources & Attribution

## Open-Meteo

CityPulse uses Open-Meteo's weather and air-quality APIs for optional live enrichment of Jaipur conditions.

Weather API documentation:
https://open-meteo.com/en/docs

Air-quality API documentation:
https://open-meteo.com/en/docs/air-quality-api

The application should retain Open-Meteo/CAMS attribution when presenting live values. Review the provider's current license/attribution terms before a public deployment.

## Synthetic hackathon feeds

Traffic, incident, emergency, parking, power, water and related civic signals included in the demo are synthetic. They exist to demonstrate the data-fusion architecture and should be replaced by verified/open civic sources before any production or public-service claim.
